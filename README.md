<h1 align="center">IVTrace</h1>

<p align="center">
  Автоматизированное снятие амплитудной характеристики датчиков тока и
  напряжения — GUI и CLI в одном приложении.
</p>

---

Источник (тока или напряжения) задаёт возбуждение на первичной обмотке
датчика, плата реле переключает полярность, мультиметр измеряет выходной
сигнал. Результат — CSV с точками измерения и PNG с графиком амплитудной
характеристики и приведённой погрешности.

## Возможности

- GUI (Tkinter) и CLI из одного исполняемого файла.
- Автообнаружение приборов по `*IDN?`, ручной ввод адреса как запасной путь.
- Обе полярности через плату реле за один проход, пресеты схемы прохода
  (сходящийся/расходящийся через ноль, полный гистерезис).
- Число витков, смещение нуля, усреднение, отсечка по погрешности.
- Приведённая погрешность по ГОСТ 8.401-80 — и в отчёте, и в живой отсечке
  во время измерения (при заданных номинале и коэффициенте преобразования).
- Плавное нарастание тока и адаптивное охлаждение (BETA).
- Свой сценарий развёртки — текстовый DSL вместо начала/конца/шага (BETA).
- Учёт межповерочных интервалов приборов, экспорт результатов в XLSX.
- Предполётные самотесты — гейт перед каждым измерением.
- Инсталлятор с автообновлением по GitHub Releases (Windows).

## Быстрый старт

### Windows — готовая сборка

1. Скачайте `IVTrace-<версия>-win64.zip` со страницы
   [Releases](https://github.com/alexlegoshin/IDM-IVTrace/releases/latest) и
   распакуйте.
2. Запустите `Setup.exe` — установит программу, создаст ярлыки и будет
   предлагать обновления при следующих запусках. Либо запустите
   `IVTrace\IVTrace.exe` напрямую — без установки, portable-режим.
3. Установите **NI-VISA** (см. ниже) — без неё программа не сможет
   разговаривать с приборами по USB.

### Из исходников — Windows / macOS / Linux

```bash
conda create -n IVTrace python=3.11 -y
conda activate IVTrace
pip install -r requirements.txt

python run.py                 # GUI (где есть дисплей)
python run.py measure ...     # измерение из консоли
python run.py analyze ...     # построение графика по CSV
python run.py selftest        # диагностика окружения
```

На macOS/Linux готовой GUI-сборки нет — только запуск из исходников
(Tkinter входит в стандартный Python). Для реальной работы с приборами
всё равно нужна NI-VISA — NI выпускает её и под Linux/macOS.

### NI-VISA

Приборы подключаются по USB-TMC и работают через **NI-VISA** — без неё
приложение измерять не будет и честно об этом скажет (индикатор в GUI,
проверка перед `measure` в CLI, команда `selftest`). Ставится один раз,
без прав администратора на последующую работу — [сайт National
Instruments](https://www.ni.com/), раздел NI-VISA.

## Приборы

| Тип | Модели |
|---|---|
| Мультиметр (ток/напряжение) | AKIP-2101 / Siglent SDM3055, АКИП-B7-78/1, RIGOL DM3068 |
| Источник тока | ITECH IT-M (АКИП-1162) |
| Источник напряжения | GW Instek GPP-74323 (Tracking Series) |
| Плата реле | Serial, автообнаружение COM-порта |

Новый прибор добавляется JSON-конфигом в `instruments/` — без кода, если
протокол укладывается в существующую схему.

## Разработка и тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```

Тесты работают на заглушках, реального железа не требуют. Тот же набор —
предполётный гейт перед каждым измерением.

## Известные ограничения

- Выход датчика по напряжению — BETA, не проверено на реальном стенде.
- Источник напряжения GPP-74323 — команды по документации производителя.
- Самотесты виртуальные: ловят поломки кода, не заменяют проверку железа.
